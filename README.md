# My-Ahk-Scripts

## 概要

My-Ahk-Scripts は、AutoHotkey v2 を用いた
**「無変換キー（vk1D）を基軸とする生産性向上ツール群」**です。

- **なぜ無変換キーか？**: ホームポジションを崩さず、親指で自然に操作レイヤーを切り替えるため。
- **設計のこだわり**: 各機能をクラス単位で分離し、個人用途として実用的に動作するレベルを目指しました。日常業務で実際に使用しているため、実用性を重視しています。

---

## デフォルト・キーマップ (Default Keymap)

設定された修飾キー（デフォルト：無変換キー `vk1D`）を基軸（以降 **MOD_KEY** と表記）として使用します。

| カテゴリ           | ホットキー                 | 動作内容                                                         |
| :----------------- | :------------------------- | :--------------------------------------------------------------- |
| **ジャンプ**       | `MOD_KEY + a`              | QuickSwitch: デフォルトへ直接ジャンプ（未設定時はメニュー表示）  |
|                    | `MOD_KEY + Shift + a`      | QuickSwitch: メニュー表示（常時）                                |
|                    | `MButton` (初期プリセット) | エクスプローラーへジャンプ（QuickSwitch デフォルト設定）         |
| **IME 制御**       | `vk1D` (無変換 単体空打ち) | **IME OFF**: 英数入力モードへ切り替え ※ModifierKeyHandler 使用時 |
|                    | `vk1C` (変換 単押し)       | **IME ON**: 日本語入力モードへ切り替え                           |
| **ランチャー**     | `MOD_KEY + f`              | フォルダナビゲーター (Navi.ahk) 起動                             |
| **入力支援**       | `MOD_KEY + s`              | スニペット選択 (SnippetPicker.ahk) 起動                          |
|                    | `MOD_KEY + Ctrl + h`       | Hotstring Manager (HotstringManager.ahk) 起動                    |
|                    | `Ctrl + ;`                 | **日付入力**: Excel 風の操作感で今日の日付を挿入                 |
| **編集・移動**     | `MOD_KEY + h/j/k/l`        | Vim 風カーソル移動 (左/下/上/右)                                 |
|                    | `MOD_KEY + r`              | 選択範囲を括弧等で囲む (WrapPalette) ※囲みの文字は自由に登録可能 |
| **メモ・ストック** | `MOD_KEY + m`              | テンポラリ・メモ (TempMemo.ahk) 起動                             |

## コンセプト： IDE サイドバー × Screenpresso の「探さない」操作感

本スイートは、「マルチモニタ環境における操作のコンテキストスイッチ削減」を目的としています。

### 開発の背景

- **課題**: ファイル操作のたびにエクスプローラーを「探して選ぶ」コストが、開発の集中力を削いでいた。
- **インスピレーション**: 画面キャプチャソフト **Screenpresso** のワークスペースのように、**「今扱っているファイルを、デスクトップの端に一時的にストックし、不要になれば即座に消す」** というテンポラリ（一時的）な操作感をファイラーでも実現したいと考えました。
- **解決案**: ファイラー（例: Tablacus Explorer）と本スイートの「QuickSwitch」を組み合わせることで、VSCode のサイドバーのような **「必要な時だけ決まった位置に出現し、不要な時は即座に消える」** 一貫した操作感を実現しました。

### 結果

ウィンドウの乱立を防ぎ、デスクトップを常にクリーンな状態に保ちながら、ファイルアクセスの際の「探す・選ぶ」という判断コストを最小化しています。

## 主な機能

### ウィンドウ・URL ジャンプ (QuickSwitch.ahk)

- **スマートな開閉制御**
  登録したウィンドウへホットキー一発でジャンプします。
  Alt+Tab のように対象を「探して選択」する必要がなく、**あらかじめ定義したウィンドウを判断を介さずワンキーで表示／最小化** できます。

  例: お気に入りのファイラーを常に決まった位置に配置しておき、中クリック 1 発で即表示・即非表示。VSCode のサイドバーを開閉するような感覚で操作できます。

  - **Before**
    - エクスプローラーや作業ウィンドウを探す必要がある
    - 既存ウィンドウを避けて操作する必要がある

  - **After**
    - ホットキー 1 発で即表示
    - 使い終わったら同じキーで即最小化
    - 常に同じ位置・同じ操作感で利用可能

- **URL / アプリ起動**: ウィンドウが存在しない場合は URL・パスを自動起動
- **2 種のキー設定**: ターゲットごとにグローバルショートカット（直接ジャンプ）とリストキー（メニュー表示中のみ）を個別に設定可能
- **プロファイル管理**: 表示するターゲットのセットをプロファイルとして切り替え可能
- **ウィンドウ自動検出**: 設定画面の「選択...」ボタンで対象ウィンドウをクリックするだけでパターンを自動入力
- **設定 GUI**: トレイメニューの「QuickSwitch Settings...」から管理

**設定例（`QuickSwitch.ini`）:**

```ini
[Targets]
; 名前=ウィンドウ検索パターン|URL/パス|ショートカットキー|リストキー
エクスプローラー=ahk_class CabinetWClass|explorer.exe|MButton|e
Notion=ahk_exe Notion.exe||^!n|n
GitHub=|https://github.com|^!g|g
```

> ウィンドウ検索パターンに一致するウィンドウが存在すればアクティブ化（再押しで最小化）、存在しなければ URL / パスを起動します。両方設定した場合はパターン優先です。

### フォルダナビゲーター (Navi.ahk)

- フォルダツリーを GUI で表示し、キーボードだけで素早く目的のフォルダへ移動
- **トグル起動**: 起動中に同じホットキー（`MOD_KEY + f`）を押すと最小化、再度押すと復元して TreeView にフォーカスを戻す
- **プロファイル管理**: 複数のルートセットをプロファイルとして保存・切り替え
  - プロファイルボタンからドロップダウンで即時切り替え（フィルター入力付き）
  - 「編集」ダイアログ内で新規作成・複製・削除・名前変更が可能
- **タブ機能**: 最大5タブを同時に開き、ルート・フィルター・マーク状態を独立して管理
  - `Ctrl+T`: 新規タブ / `Ctrl+W`: タブを閉じる / `Ctrl+Tab`: 次のタブ / `Ctrl+1-5`: 直接切り替え
  - タブ内でルート切り替え履歴を `Alt+←/→` で前後移動可能
  - タブが1枚のときはタブバーを自動非表示
- **フォルダフィルター**: キーワードを入力するだけでツリーをリアルタイム絞り込み
  - **最後のキーワード**はフォルダ名にマッチ、**それ以前のキーワード**はパス全体にマッチ
  - 例: `src` → 「src」という名のフォルダ / `myapp src` → myapp 配下にある src フォルダ
  - `|` 区切りで OR 検索（例: `2024|2025 report` → 2024 か 2025 を含むパスの report フォルダ）
  - `Esc` でフィルタークリア
  - [fd](https://github.com/sharkdp/fd)（高速ファイル検索ツール）がある場合はフィルターを高速化可能（「編集」→ ルートディレクトリ編集 から設定）
  - fd インデックス構築中はステータスバーにアニメーションドットを表示
  - **ネットワーク上のフォルダをルートにする場合は注意**: フォルダフィルターとファイル検索はフォルダを再帰的にスキャンするため、大量のファイルアクセスが発生しサーバー負荷や遅延につながる
    - ローカルドライブ（`C:\` など）は問題なし
    - `\\server\share` 形式（UNC パス）は自動検出して fd とプリフェッチを無効化（サーバー負荷対策）
    - ネットワークドライブをドライブレターに割り当てた場合（例: `Z:\` → 実体はファイルサーバー）は自動検出できないため、以下で手動無効化を推奨：
      - フォルダフィルター fd: 「編集」→「フォルダフィルター」→「高速化する（fd.exe が必要）」のチェックを外す
      - ファイル検索 fd: アクションメニュー → `F`（キーワード検索）→「検索設定」→「fd を使用して高速検索」のチェックを外す
- **マーク機能**: 任意のフォルダ/ファイルを緑色でマークし、マーク済みアイテムだけに絞り込み表示可能
  - `Alt+M`: マークのトグル / `Ctrl+M`: マークフィルターのオン/オフ / `Alt+Shift+M`: 全マーク解除
  - マーク状態はタブごとに独立して保持
- **ファイル表示モード**: チェックをONにするとフォルダ展開時にファイルも自動表示
- **アクションメニュー** (`Space` キー):
  - `E`: エクスプローラーで開く
  - `T`: ユーザー指定のファイラーで開く
  - `V`: **VSCode** で開く
  - `P`: PowerShell を当該ディレクトリで起動
  - `C`: コマンドプロンプトを当該ディレクトリで起動
  - `K`: パスをクリップボードにコピー
  - `F`: 選択フォルダ内をキーワード検索（結果をリスト表示）
  - `R`: Explorer と同等の右クリックメニューを表示（TreeView 上での右クリックでも起動）
    - 「送る」サブメニューに対応（.lnk / .vbs / .bat / .cmd ターゲットを実行可能）
    - 削除・切り取り・名前の変更はデフォルトで非表示（誤操作防止）
    - 有効化する場合は `Navi.ContextMenu.ahk` の `HIDE_DANGEROUS_CTX_ITEMS` を `false` に変更
  - ※ファイル選択時に E/T を実行すると親フォルダを開く
- **ショートカット**:
  - `Ctrl+F`: フォルダフィルターにフォーカス
  - `Ctrl+D`: 選択フォルダの詳細ファイルリストを表示
  - `Ctrl+P`: ピン留めトグル（ONのとき操作後もウィンドウを閉じない）
  - `F1`: ショートカット一覧ヘルプを表示
- アクションを行ったパスを記憶し、次回起動時にフォーカスを復旧
- ウィンドウのリサイズに対応

### スニペット挿入支援(SnippetPicker.ahk)

- 定型文を一覧から検索・選択して挿入
- 日付入力などの動的な入力にも対応
- コーディング・業務文書入力の高速化を目的とした設計
- 汎用ツールをあえて使わず、メモリ使用量を抑えるために AHK ネイティブで実装
- **プレースホルダ置換エンジン搭載** 定型文の中に以下を含めることで、挿入時に動的に展開
  | プレースホルダ | 内容 |
  | :--- | :--- |
  | `{{clip}}` | クリップボードの内容 |
  | `{{cursor}}` | 挿入後のカーソル位置を指定 |
  | `{{N:ラベル}}` | 穴埋めフィールド（例: `{{1:会社名}}`）。挿入時に Fill In フォームが開き、フィールドを順番に入力してから挿入される |
  | `yyyy/mm/dd` | 今日の日付（例: 2025/04/29） |
  | `HH:mm` | 現在時刻（例: 09:30） |
- **プレフィックス検索**: 検索欄で列を指定して絞り込み可能
  - `g:キーワード` → グループ列を検索
  - `c:キーワード` → 内容列を検索
  - プレフィックスなし → 名称列を検索（デフォルト）
- **グループ絞り込み**: グループボタンまたは `Ctrl+G` でフローティングピッカーを開き、キーボードだけでグループを切り替え可能
- 特定グループで絞り込み中はグループ列を自動非表示にし、名称・内容列を広く表示
- 内容列にホバーするとツールチップでフル内容を表示
- タイトルバーに現在の表示件数を表示
- フォーカス離脱で自動非表示 / `Esc` で検索文字をクリア（文字がなければ閉じる）

### 修飾キー制御 (ModifierKeyHandler.ahk)

- **OS 標準動作のブロック**
  無変換キーなどの修飾キーを OS 側に渡さないことで、意図しない動作（カタカナモードへの切り替えなど）を防ぎます。

- **空打ち（タップ）検出**
  修飾キーを単体で押した場合と、他のキーと組み合わせた場合を自動判別します。

- **柔軟な設定**
  2 つのモードから選択可能：

  - **モード 1**: 空打ち時に IME 切り替え + キー無効化（デフォルト）
  - **モード 2**: キー無効化のみ（IME 機能不要なユーザー向け）

- **簡単なキー変更**
  無変換キーだけでなく、CapsLock、Space、Right Alt など、任意の修飾キーに対応可能です。

  ```autohotkey
  ; Main.ahk での設定例
  ModifierKeyHandler.Init("vk1D", "sc07B")  ; 無変換キー（デフォルト）
  ModifierKeyHandler.OnTap := (*) => ImeControl.Toggle(false)  ; 空打ちでIME OFF

  ; キー無効化のみ使いたい場合は OnTap を設定しない
  ; ModifierKeyHandler.Init("vk1D", "sc07B")
  ```

### Vim 風カーソルナビゲーション(VimNavigation.ahk)

- 無変換キーを押しながら `h/j/k/l` でカーソル移動
- Shift キー併用による範囲選択に対応
- ホームポジションを崩さない操作体系

### テキスト囲みユーティリティ(WrapPalette.ahk)

- 選択範囲を括弧・引用符などで即座に囲む

- **自由なパーツ登録**: HTML タグ、括弧、引用符、コードブロックなど、任意の囲み文字を登録可能
- **複数行パーツ対応**: 改行を含むコードスニペットやテンプレートも登録可能
- GUI による直感的な操作が可能
- **トリガキーによる即実行**: 1 文字のショートカットで即座に適用

### テンポラリ・メモ (TempMemo.ahk)

- タブ形式で情報をクイックにストックできるスクラップパッド
- **EOL 正規化**: 貼り付け時に改行コードを自動修正し、ブラウザからのコピーが 1 行になる問題を防止
- **開発者向け表示**: 等幅フォント・折り返し無効・透明度調整など、コードの断片保持に最適化

### ホットストリング管理 (HotstringManager.ahk)

- あらかじめ登録した数文字の「短縮文字」を入力するだけで、あらかじめ設定した定型文やコマンドへ即座に自動変換
- **動的な登録と反映** INI ファイルによる永続化を行い、スクリプトの再起動なしで新しいホットストリングを即座に反映
- **プレースホルダ対応** スニペット機能と同様の置換エンジンを備え、`{{clip}}`・`{{cursor}}`・`{{N:ラベル}}`・日付・時刻を組み合わせた動的な短縮入力をサポート

### その他ユーティリティ(ImeControl.ahk)

- IME 状態制御
- 日付・時刻の即時入力
- 作業フォルダのクイック起動／切り替え

## 設計方針

- **機能単位の分離**
  各機能をクラスとして実装し、Main.ahk で統合しています。

- **個人設定の除外**
  `.gitignore`でホワイトリスト方式を採用し、個人用の`.ini`ファイルはコミットされないようにしています。

- **初回起動時の設定**
  実行環境に依存するパスは初回起動時にユーザーが指定できるようにしています。

- **モジュール式設計**
  不要な機能は簡単に無効化できます。例えば、ModifierKeyHandler の IME 切り替え機能が不要な場合、`OnTap` の設定をコメントアウトするだけでキー無効化のみの動作に切り替わります。

## カスタマイズ（修飾キーとホットキーの変更）

本スイートは「どのキーを修飾キーにするか（配線）」と「何を実行するか（ロジック）」を分離して設計しています。

### 1. メイン修飾キー（レイヤー）の変更

`Main.ahk` 冒頭の `MOD_KEY` 変数を書き換えるだけで、Vim 操作や各ツール呼び出しの基軸となるキーを一括変更できます。

```autohotkey
; Main.ahk 冒頭の設定例
MOD_KEY := "vk1D"      ; 無変換 (JIS配列：親指操作に最適)
; MOD_KEY := "CapsLock"  ; CapsLock (US配列：小指操作に最適)
; MOD_KEY := "RAlt"      ; 右Alt (US配列等、親指位置にAltがある場合)
```

### 2. ModifierKeyHandler のキー変更

ModifierKeyHandler で制御するキーも、`Main.ahk` で簡単に変更できます。

```autohotkey
; Main.ahk での ModifierKeyHandler 設定例

; 無変換キーを使用（デフォルト）
ModifierKeyHandler.Init("vk1D", "sc07B")

; CapsLock を使用
; ModifierKeyHandler.Init("vkF0", "sc03A")

; Space を使用
; ModifierKeyHandler.Init("vk20", "sc039")

; Right Alt を使用
; ModifierKeyHandler.Init("vkA5", "sc138")
```

### 3. IME 切り替え機能の有効/無効

```autohotkey
; Main.ahk での設定

; モード1: 空打ちでIME切り替え（デフォルト）
ModifierKeyHandler.Init("vk1D", "sc07B")
ModifierKeyHandler.OnTap := (*) => ImeControl.Toggle(false)

; モード2: キー無効化のみ（IME切り替え不要な場合）
; ModifierKeyHandler.Init("vk1D", "sc07B")
; OnTapを設定しない = キー無効化のみ
```

### 4. その他のホットキー定義

マウスボタンや特定のキーへの直接割り当ては、修飾キーの定義とは独立して Main.ahk で自由に定義可能です。

```autohotkey
; 設定例：デバイスに合わせたトリガー設定
#HotIf GetKeyState("vk1D", "P")
a::  QuickSwitch.Show()      ; 無変換 + a でデフォルトジャンプ（未設定時はメニュー）
+a:: QuickSwitch.ShowMenu()  ; 無変換 + Shift + a で常にメニュー表示
#HotIf
^;::DateTimeInsert.Execute()             ; Ctrl + ; で日付入力
```

## オプション機能

### Excel セル操作 (ExcelFontStyle.ahk)

Excel 専用のセル書式・行列操作をホットキーで実行するオプションモジュールです。フォントカラー変更・取り消し線・背景色トグル・行列挿入削除・セル結合解除に対応しています。

> **注意**: デフォルトでは `Main.ahk` に含まれていません。`Main.ahk` の該当コメントブロック（`/*` と `*/`）を外すと有効化されます。

---

### AI テキスト処理 (SnapAI.ahk)

選択テキストや手入力のテキストを LLM API に送信し、翻訳・要約・説明などを行うオプションツールです。

> **注意**: このツールは選択テキストを外部 API に送信します。個人情報・社外秘データなど、外部に送信したくない内容を含む場合はご注意ください。デフォルトでは `Main.ahk` に含まれていません。有効化は手動で行ってください。

#### 有効化の手順

1. `Main.ahk` に以下を追記します:

   ```autohotkey
   ;  AI テキスト処理 (SnapAI)
   #Include "ui\SnapAI.ahk"
   SnapAI.Init()
   t:: SnapAI.Show()           ; 好みのホットキーに変更可
   ```

2. スクリプト起動後、トレイメニューまたはホットキーから **設定** を開き、API キーとエンドポイントを設定します。

#### 主な機能

- テキストを選択してホットキーを押すと、登録済みプロンプト一覧が表示されます
- テキスト未選択時は手入力モードが起動し、テキストとプロンプトを自由に入力できます
- 保存プロンプトを INI ファイルで管理・追加可能
- 処理中はプログレス GUI を表示し、キャンセルボタンで中断可能（30 秒でタイムアウト）
- 結果をクリップボードに自動コピーするオプションあり

#### 対応 API

OpenAI 互換のエンドポイントであれば利用可能です。

| サービス          | エンドポイント例                                  |
| :---------------- | :------------------------------------------------ |
| OpenAI            | `https://api.openai.com/v1/chat/completions`      |
| Groq              | `https://api.groq.com/openai/v1/chat/completions` |
| OpenRouter        | `https://openrouter.ai/api/v1/chat/completions`   |
| Ollama (ローカル) | `http://localhost:11434/v1/chat/completions`      |

> Ollama などのローカルエンドポイント（`localhost`）の場合、API キーの入力は不要です。

## 動作環境

- **OS**: Windows 10 / 11 (64bit 推奨)
- **Runtime**: [AutoHotkey v2.0+](https://www.autohotkey.com/)
- **ファイラーについて(QuickSwitch・Navi 使用時など)**:
  - 標準のエクスプローラーを含む任意のファイラーで動作します。
  - ウィンドウを一つに集約できる**シングルトン管理**に対応したファイラーを使うと、QuickSwitch との組み合わせでより快適に利用できます。

## セットアップ

1. **AutoHotkey v2** をインストールします。
2. 本リポジトリを `git clone` または ZIP でダウンロードします。
3. `Main.ahk` を実行することで、全機能が有効化されます。
   - ※初回起動時に設定ファイル（.ini）が自動生成されます。
