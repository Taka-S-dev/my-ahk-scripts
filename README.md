# My-Ahk-Scripts

## 概要

My-Ahk-Scripts は、AutoHotkey v2 を用いた  
**「無変換キー（vk1D）を基軸とする生産性向上ツール群」**です。

- **なぜ無変換キーか？**: ホームポジションを崩さず、親指で自然に操作レイヤーを切り替えるため。
- **設計のこだわり**: 各機能をクラス単位で分離し、個人用途として実用的に動作するレベルを目指しました。日常業務で実際に使用しているため、実用性を重視しています。

---

## デフォルト・キーマップ (Default Keymap)

設定された修飾キー（デフォルト：無変換キー `vk1D`）を基軸（以降 **MOD_KEY** と表記）として使用します。
| カテゴリ | ホットキー | 動作内容 |
| :----------------- | :--------------------- | :------------------------------------------------------------ |
| **フォルダ操作** | `MButton` (中クリック) | フォルダトグラー（表示/最小化）の実行 |
| **IME 制御** | `vk1D` (無変換 単体空打ち) | **IME OFF**: 英数入力モードへ切り替え ※ModifierKeyHandler 使用時 |
| | `vk1C` (変換 単押し) | **IME ON**: 日本語入力モードへ切り替え |
| **ランチャー** | `MOD_KEY + f` | フォルダナビゲーター (Navi.ahk) 起動 |
| | `MOD_KEY + t` | Navi: Tablacus Explorer で開く (Navi 選択中のみ) |
| | `MOD_KEY + v` | Navi: VSCode で開く (Navi 選択中のみ) |
| | `MOD_KEY + c` | Navi: コマンドプロンプトで開く (Navi 選択中のみ) |
| **入力支援** | `MOD_KEY + s` | スニペット選択 (SnippetPicker.ahk) 起動 |
| | `(Picker中) ;today` | **クイックトリガ**: 今日の日付を動的に生成して挿入 |
| | `Ctrl + ;` | **日付入力**: Excel 風の操作感で今日の日付を挿入 |
| **編集・移動** | `MOD_KEY + h/j/k/l` | Vim 風カーソル移動 (左/下/上/右) |
| | `MOD_KEY + r + 記号` | 選択範囲を括弧等で囲む (WrapPalette) ※対応記号: " ' ( [ { < `|
| **メモ・ストック** |`MOD_KEY + m` | テンポラリ・メモ (TempMemo.ahk) 起動 |

## コンセプト： IDE サイドバー × Screenpresso の「探さない」操作感

本スイートは、「マルチモニタ環境における操作のコンテキストスイッチ削減」を目的としています。

### 開発の背景

- **課題**: ファイル操作のたびにエクスプローラーを「探して選ぶ」コストが、開発の集中力を削いでいた。
- **インスピレーション**: 画面キャプチャソフト **Screenpresso** のワークスペースのように、**「今扱っているファイルを、デスクトップの端に一時的にストックし、不要になれば即座に消す」** というテンポラリ（一時的）な操作感をファイラーでも実現したいと考えました。
- **解決案**: 高度な拡張性を持つ **Tablacus Explorer** を基盤とし、本スイートの「フォルダトグラー」を組み合わせることで、VSCode のサイドバーのような **「必要な時だけ決まった位置に出現し、不要な時は即座に消える」** 一貫した操作感を実現しました。

### 結果

ウィンドウの乱立を防ぎ、デスクトップを常にクリーンな状態に保ちながら、ファイルアクセスの際の「探す・選ぶ」という判断コストを最小化しています。

## 主な機能

### フォルダトグラー (FolderToggle.ahk)

- **スマートな開閉制御**  
  特定のホットキーにより、ファイラーの表示／非表示を即座に切り替えます。  
  Alt+Tab のように対象を「探して選択」する必要がなく、  
  あらかじめ定義したファイラーを **判断を介さずワンキーで表示／非表示** できます。

  - **Before**

    - エクスプローラを探す必要がある
    - 既存ウィンドウを避けて操作する必要がある

  - **After**
    - ホットキー 1 発で即表示
    - 使い終わったら即非表示
    - 常に同じ位置・同じ操作感で利用可能

### フォルダランチャー / ナビゲーション(Navi.ahk)

- 無変換キーを起点としたショートカット操作
- フォルダ一覧を GUI で表示し、素早く選択・移動
- **開発環境の統合ハブ**:
  目的のフォルダを特定後、用途に合わせて即座にディレクトリを展開します。
  - `vk1D + v`: **VSCode** で開く
  - `vk1D + c`: **コマンドプロンプト** で開く
  - `vk1D + t`: **Tablacus Explorer**（または任意のエクスプローラ）で開く

### スニペット挿入支援(SnippetPicker.ahk)

- 定型文を一覧から検索・選択して挿入
- 日付入力などの動的な入力にも対応
- コーディング・業務文書入力の高速化を目的とした設計
- 汎用ツールをあえて使わず、メモリ使用量を極限まで抑えるために AHK ネイティブで実装
- 隠しパラメータ（プレフィックス）による分類・抽出機能により高速検索可能

### 修飾キー制御 (ModifierKeyHandler.ahk)

- **OS 標準動作のブロック**  
  無変換キーなどの修飾キーを OS 側に渡さないことで、意図しない動作（カタカナモードへの切り替えなど）を防ぎます。

- **空打ち（タップ）検出**  
  修飾キーを単体で押した場合と、他のキーと組み合わせた場合を自動判別します。

- **柔軟な設定**  
  2 つのモードから選択可能：

  - **モード 1**: 空打ち時に IME 切り替え + キー無効化（デフォルト）
  - **モード 2**: キー無効化のみ（IME 機能不要なユーザー向け）

- **簡単なキー変更**  
  無変換キーだけでなく、CapsLock、Space、Right Alt など、任意の修飾キーに対応可能です。

  ```autohotkey
  ; Main.ahk での設定例
  ModifierKeyHandler.Init("vk1D", "sc07B")  ; 無変換キー（デフォルト）
  ModifierKeyHandler.OnTap := (*) => ImeControl.Toggle(false)  ; 空打ちでIME OFF

  ; キー無効化のみ使いたい場合は OnTap を設定しない
  ; ModifierKeyHandler.Init("vk1D", "sc07B")
  ```

### Vim 風カーソルナビゲーション(VimNavigation.ahk)

- 無変換キーを押しながら `h/j/k/l` でカーソル移動
- Shift キー併用による範囲選択に対応
- ホームポジションを崩さない操作体系

### テキスト囲みユーティリティ(WrapPalette.ahk)

- 選択範囲を括弧・引用符などで即座に囲む
- 入力待機型の操作により、最小キー数で完結

### テンポラリ・メモ (TempMemo.ahk)

- タブ形式で情報をクイックにストックできるスクラップパッド
- **EOL 正規化**: 貼り付け時に改行コードを自動修正し、ブラウザからのコピーが 1 行になる問題を防止
- **開発者向け表示**: 等幅フォント・折り返し無効・透明度調整など、コードの断片保持に最適化

### その他ユーティリティ(ImeControl.ahk/Hotstrings.ahk)

- IME 状態制御
- 日付・時刻の即時入力
- 作業フォルダのクイック起動／切り替え

## 設計方針

- **機能単位の分離**  
  各機能をクラスとして実装し、Main.ahk で統合しています。

- **個人設定の除外**  
  `.gitignore`でホワイトリスト方式を採用し、個人用の`.ini`ファイルはコミットされないようにしています。

- **初回起動時の設定**  
  実行環境に依存するパスは初回起動時にユーザーが指定できるようにしています。

- **モジュール式設計**  
  不要な機能は簡単に無効化できます。例えば、ModifierKeyHandler の IME 切り替え機能が不要な場合、`OnTap` の設定をコメントアウトするだけでキー無効化のみの動作に切り替わります。

## カスタマイズ（修飾キーとホットキーの変更）

本スイートは「どのキーを修飾キーにするか（配線）」と「何を実行するか（ロジック）」を分離して設計しています。

### 1. メイン修飾キー（レイヤー）の変更

`Main.ahk` 冒頭の `MOD_KEY` 変数を書き換えるだけで、Vim 操作や各ツール呼び出しの基軸となるキーを一括変更できます。

```autohotkey
; Main.ahk 冒頭の設定例
MOD_KEY := "vk1D"      ; 無変換 (JIS配列：親指操作に最適)
; MOD_KEY := "CapsLock"  ; CapsLock (US配列：小指操作に最適)
; MOD_KEY := "RAlt"      ; 右Alt (US配列等、親指位置にAltがある場合)
```

### 2. ModifierKeyHandler のキー変更

ModifierKeyHandler で制御するキーも、`Main.ahk` で簡単に変更できます。

```autohotkey
; Main.ahk での ModifierKeyHandler 設定例

; 無変換キーを使用（デフォルト）
ModifierKeyHandler.Init("vk1D", "sc07B")

; CapsLock を使用
; ModifierKeyHandler.Init("vkF0", "sc03A")

; Space を使用
; ModifierKeyHandler.Init("vk20", "sc039")

; Right Alt を使用
; ModifierKeyHandler.Init("vkA5", "sc138")
```

### 3. IME 切り替え機能の有効/無効

```autohotkey
; Main.ahk での設定

; モード1: 空打ちでIME切り替え（デフォルト）
ModifierKeyHandler.Init("vk1D", "sc07B")
ModifierKeyHandler.OnTap := (*) => ImeControl.Toggle(false)

; モード2: キー無効化のみ（IME切り替え不要な場合）
; ModifierKeyHandler.Init("vk1D", "sc07B")
; OnTapを設定しない = キー無効化のみ
```

### 4. その他のホットキー定義

マウスボタンや特定のキーへの直接割り当ては、修飾キーの定義とは独立して Main.ahk で自由に定義可能です。

```autohotkey
; 設定例：デバイスに合わせたトリガー設定
MButton::FolderToggle.Execute()         ; マウス中ボタンでフォルダ開閉
XButton1::FolderToggle.Execute()        ; マウスサイドボタンでフォルダ開閉
^;::DateTimeInsert.Execute()            ; Ctrl + ; で日付入力
```

## 動作環境

- **OS**: Windows 10 / 11 (64bit 推奨)
- **Runtime**: [AutoHotkey v2.0+](https://www.autohotkey.com/)
- **ファイラーについて(フォルダトグラー使用時など)**:
  - 標準のエクスプローラーでも全ての機能が動作します。
  - **推奨環境**: [Tablacus Explorer](https://tablacus.github.io/explorer_en.html)
    - **推奨理由**:
      1. **シングルトン管理**: ウィンドウを一つに集約できるため、デスクトップの乱立を防げます。
      2. **エクスプローラーの統合**: 標準エクスプローラーをタブとして取り込む機能があり、本スイートの目的と相性が良いためです。

## セットアップ

1. **AutoHotkey v2** をインストールします。
2. 本リポジトリを `git clone` または ZIP でダウンロードします。
3. `Main.ahk` を実行することで、全機能が有効化されます。
   - ※初回起動時に設定ファイル（.ini）が自動生成されます。
